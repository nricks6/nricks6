# Hi, I'm Nate 👋

I've spent 8 years in strategy and growth across Goldman Sachs, venture capital and high-growth startups. I'm not a traditional engineer: I use AI coding tools and agents to turn business problems into working software.

## What I've built

- **[Hyrox Training App](https://github.com/nricks6/hyrox-training-app):** a workout planner and tracker for Hyrox training, built with my AI agent
- **[Speed Reader](https://github.com/nricks6/speed-reader):** a Chrome extension that flashes articles one word at a time for faster reading
- **[Gmail GPT Drafter](https://github.com/nricks6/gmail-gpt-drafter):** a Python tool that reads unread email and saves AI-written reply drafts to Gmail
- **[Prompt Playground](https://github.com/nricks6/prompt-playground-cli):** a command-line tool for comparing prompt versions, token use and cost
- **[OSS Issue Prioritizer](https://github.com/nricks6/firecrawl-oss-prioritizer):** a script that uses an LLM to label GitHub issues P0, P1 or P2

## How I work

I start with the problem, build a working version quickly and improve it through use. Much of my recent work is in private repos, and many of those commits are made by my AI agent, which I direct and review.
